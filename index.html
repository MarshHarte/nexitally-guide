GUIDE / 使用指南

日常工作连接与设备管理

01

先确认同时在线规则

区分设备数量与不同公网 IP 数量。电脑和手机在不同网络下使用时，可能涉及不同的计数方式。

02

为工作应用固定选择

在满足业务要求的地区验证实际应用，记录可用节点与客户端版本，减少工作过程中不必要的切换。

03

换网络后重新确认

从办公室转到移动网络时，重新检查连接和账户提示，避免将环境变化误判为账户失效。

QUESTIONS / 常见问题

关于Nexitally，你可能想了解

奶昔与 Nexitally 是两套入口吗？

这里使用两个名称说明同一品牌。请按本页列出的具体域名访问，不凭相似拼写寻找替代地址。

在两台设备登录就等于两台都能连接吗？

登录和同时在线限制不同，仍需核对套餐允许的连接数及 IP 规则。

Nexitally：办公用机场与 VPN 加速器，怎样核对接入需求？

VPN 通常指虚拟专用网络；本指南中的“机场”指订阅代理服务，“加速器”是更宽泛的软件或服务称呼，具体接入能力以账户文档为准。

“科学上网”和“魔法”是网络访问场景中的常见俗称，不是固定协议、独立套餐或速度保证。

先确认常用工作应用、设备与公网 IP 规则，再在自己的网络中验证登录和业务功能。这里的个人订阅不能自动替代企业内部网络的 VPN 配置。
