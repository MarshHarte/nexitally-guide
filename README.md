## 日常工作连接与设备管理

Nexitally 通常也称奶昔机场。本指南关注持续工作场景中的设备、出口与账户管理，让登录入口、订阅配置和日常连接各有清楚的位置。

### 1. 先确认同时在线规则

区分设备数量与不同公网 IP 数量。电脑和手机在不同网络下使用时，可能涉及不同的计数方式。

### 2. 为工作应用固定选择

在满足业务要求的地区验证实际应用，记录可用节点与客户端版本，减少工作过程中不必要的切换。

### 3. 换网络后重新确认

从办公室转到移动网络时，重新检查连接和账户提示，避免将环境变化误判为账户失效。

## 使用体验如何检查

把地区、运营商、时段、客户端版本和目标应用保持一致，再比较连接结果。持续访问、下载峰值和应用地区识别是不同指标；失败或超时也应记录。本文未发布本次实测速度或实时节点状态。

可在自己的设备上记录以下信息，向账户支持反馈时隐藏个人凭据：

| 记录项 | 填写方式 |
| --- | --- |
| 设备与网络 | 系统、客户端版本、运营商及 Wi-Fi／移动数据 |
| 当前配置 | 节点名称、订阅更新时间，不记录密钥 |
| 具体场景 | 应用名称、操作步骤与观察到的结果 |
| 发生时间 | 注明日期、时间及所在时区 |

## Nexitally常见问题

### 奶昔与 Nexitally 是两套入口吗？

这里使用两个名称说明同一品牌。请按本页列出的具体域名访问，不凭相似拼写寻找替代地址。

### 在两台设备登录就等于两台都能连接吗？

登录和同时在线限制不同，仍需核对套餐允许的连接数及 IP 规则。

### 当前套餐价格与活动在哪里确认？

进入账户查看当前订单，核对实付金额、付款周期、流量重置、有效期、设备限制与售后条件。历史截图和旧优惠码不能代替当前交易条款。
